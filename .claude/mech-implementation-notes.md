# Starfinder Mech Support Implementation Notes

## Overview

This document captures the implementation of mech support for the FoundryVTT Starfinder system, based on the Tech Revolution sourcebook rules.

## Starfinder Mech Rules Summary

Mechs are immense robots piloted by one or more operators, combining armor, agility, and firepower. Key mechanics:

### Mech Statistics
- **Tier**: Overall power level, impacts statistics
- **Size**: Huge, Gargantuan, or Colossal
- **HP**: Base HP from frame/limbs + (HP Advancement × tier)
- **Shield Points (SP)**: Personal force shields that absorb damage before HP
- **Hardness**: Reduces incoming damage
- **EAC/KAC**: Armor classes determined by tier, frame, and limbs
- **Effective Strength**: For melee damage, Strength checks, carrying capacity
- **Attack Bonus**: Based on tier
- **Reach**: 15 ft (Huge), 20 ft (Gargantuan), 30 ft (Colossal)
- **Senses**: Low-light vision, darkvision 120 ft, blindsense (vibration) 30 ft
- **Immunities**: Construct immunities

### Mech Points (MP)
- Party pool used to build mechs
- Each PC contributes points based on level
- Spent on frames, limbs, weapons, auxiliary systems, upgrades

### Power Points (PP)
- Generated by power core
- Initial PP, maximum PP, and regen per turn
- Used to supercharge systems and perform special actions

### System Damage
- At 2/3 and 1/3 HP, systems can malfunction
- States: Nominal → Malfunctioning → Inoperable
- Affects: Upper limbs, lower limbs, frame, power core, auxiliary systems

### Building a Mech
1. Conceptualize purpose and operator count
2. Calculate Mech Points pool
3. Select Frame (determines size, base HP, slots, operator range)
4. Select Upper/Lower Limbs
5. Select Power Core (PP initial/max/regen)
6. Add Weapons to slots
7. Add Auxiliary Systems
8. Add Upgrades with remaining MP

## Implementation Details

### Files Created

#### Actor Data Model
- **`src/module/data/actor/mech.mjs`** - Mech actor data model
  - Extends `SFRPGActorBase`
  - Uses `conditionsTemplate()` and `crewTemplate({type: "mech"})`
  - Attributes: hp, sp, hardness, eac, kac, strength, attackBonus, pp, speed, reach, senses, size, systems, slots
  - Currency: mp (Mech Points)
  - Details: tier, frame, model, notes, source

#### Item Data Models
- **`src/module/data/item/mechFrame.mjs`** - Frame item
  - size, baseHp, hpAdvancement, hardness, eacBonus, kacBonus, speed
  - operatorsMin, operatorsMax, frameSlots, auxSlots, mpCost

- **`src/module/data/item/mechWeapon.mjs`** - Weapon item
  - Uses `actionTemplate()` and `activatedEffectTemplate()`
  - weaponType (melee/ranged), slot assignment, damage, range, area
  - capacity, usage, special properties, ppCost, mpCost, save DC

- **`src/module/data/item/mechAuxiliary.mjs`** - Auxiliary system item
  - canBeActivated, isActive, ppCost, mpCost

- **`src/module/data/item/mechUpgrade.mjs`** - Upgrade item
  - mpCost

#### Actor Sheet
- **`src/module/actor/sheet/mech.js`** - Sheet class
  - Extends `ActorSheetSFRPG`
  - Accepts `mechDefinitionItemTypes` and `physicalItemTypes`
  - Tabs: details, components, weapons, operators, notes
  - Handles crew/operator management

#### Templates
- **`static/templates/actors/mech-sheet-full.hbs`** - Full actor sheet
- **`static/templates/actors/mech-sheet-limited.hbs`** - Limited view
- **`static/templates/items/mechFrame.hbs`** - Frame item sheet
- **`static/templates/items/mechWeapon.hbs`** - Weapon item sheet
- **`static/templates/items/mechAuxiliary.hbs`** - Auxiliary item sheet
- **`static/templates/items/mechUpgrade.hbs`** - Upgrade item sheet

## Config Entries Reference

```javascript
// Actor type
SFRPG.actorTypes.mech = "TYPES.Actor.mech"

// Sizes (mechs are always large-scale)
SFRPG.mechSizes = {
    "huge": "SFRPG.SizeHuge",
    "gargantuan": "SFRPG.SizeGargantuan",
    "colossal": "SFRPG.SizeColossal"
}

// System damage states
SFRPG.mechSystemStatus = {
    "nominal": "SFRPG.MechSheet.Systems.StatusNominal",
    "malfunctioning": "SFRPG.MechSheet.Systems.StatusMalfunctioning",
    "inoperable": "SFRPG.MechSheet.Systems.StatusInoperable"
}

// Weapon types
SFRPG.mechWeaponTypes = {
    "melee": "SFRPG.MechSheet.Weapon.TypeMelee",
    "ranged": "SFRPG.MechSheet.Weapon.TypeRanged"
}

// Weapon slot locations
SFRPG.mechWeaponSlots = {
    "frame": "SFRPG.MechSheet.Weapon.SlotFrame",
    "upperLimb": "SFRPG.MechSheet.Weapon.SlotUpperLimb",
    "lowerLimb": "SFRPG.MechSheet.Weapon.SlotLowerLimb"
}

// Item type grouping
SFRPG.mechDefinitionItemTypes = [
    "mechFrame",
    "mechWeapon",
    "mechAuxiliary",
    "mechUpgrade"
]
```

## Troubleshooting

If mech doesn't appear in actor creation dropdown:

1. **Clear browser cache** - FoundryVTT caches JavaScript heavily
   - Hard refresh: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)

2. **Check browser console** (F12) for JavaScript errors
   - Any error in mech files could prevent system initialization

3. **Verify system version** - Ensure FoundryVTT loaded the correct branch
   - Check `Data/systems/sfrpg/src/module/config.js` for `"mech"` entry

4. **Restart FoundryVTT server** completely
